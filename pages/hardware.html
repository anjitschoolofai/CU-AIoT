How to Connect a DeviceESP32 / Raspberry Pi via MQTT

To display real hardware data, configure your device to publish sensor readings as JSON to an MQTT broker accessible from this computer, then configure the connection below.

1. Required Setup

▼
  • An MQTT broker reachable from this browser (e.g. broker.local:1883 or a cloud broker)
  • Your device (ESP32 / Raspberry Pi) publishing JSON over MQTT
  • A WebSocket-enabled broker for browser-side subscription (port 9001 by default)
  • Device firmware or Python script posting to the agreed topic

2. MQTT Topic & Payload Schema

▼

Publish to topic: campus/[location]/[nodeid]/telemetry

// Example MQTT payload (JSON)
{
  "ts": "2026-11-03T09:14:32+05:30",
  "node": "esp32-node07",
  "temp_c": 26.4,
  "hum_pct": 58.2,
  "vib_mm_s": 0.12,
  "rssi": -67
}

3. ESP32 Arduino Sketch (Outline)

▼
// Requires: PubSubClient, DHT, ArduinoJson libraries
// Configure WiFi SSID, password and broker IP in config.h
// NOTE: Never hardcode credentials — use a config file excluded from source control

#include <WiFi.h>
#include <PubSubClient.h>
#include <DHT.h>
#include <ArduinoJson.h>

// See manufacturer datasheets for correct wiring and voltage (3.3V for ESP32)
void loop() {
  float t = dht.readTemperature();
  float h = dht.readHumidity();
  // Validate readings before publishing
  if (!isnan(t) && !isnan(h)) publishReading(t, h);
  delay(5000);
}
ℹ️ Always consult the ESP32 and sensor datasheets for correct voltage (3.3V GPIO), current limits and wiring before connecting hardware.

4. Raspberry Pi Python Script (Outline)

▼
# Install: pip install paho-mqtt RPi.GPIO Adafruit_DHT
# Requires MQTT broker accessible on the network

import paho.mqtt.client as mqtt, json, time
# from Adafruit_DHT import DHT22, read_retry

BROKER = "broker.local" # Replace with actual broker IP
TOPIC = "campus/lab/node01/telemetry"

client = mqtt.Client()
client.connect(BROKER, 1883)

while True:
  # humidity, temp = read_retry(DHT22, 4)
  payload = json.dumps({"ts": time.strftime("%H:%M:%S"), "temp_c": temp, "hum_pct": humidity})
  client.publish(TOPIC, payload)
  time.sleep(5)
