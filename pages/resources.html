Open-source data visualization and alerting dashboard. Works with InfluxDB, PostgreSQL, Prometheus and more.

grafana.com

ThingsBoard

Open-source IoT platform for device management, data collection, processing and visualization. Free Community Edition available.

thingsboard.io
🦟

Eclipse Mosquitto

Lightweight open-source MQTT broker. Easy to install on Raspberry Pi or PC. Supports TLS and authentication.

mosquitto.org

scikit-learn.org

influxdata.com

arduino.cc/en/software

mqttx.app

Hardware Reference Guides

🔌 Always consult the official manufacturer datasheet before connecting any sensor or module. Pay attention to voltage levels (3.3V vs 5V), current limits and GPIO pin compatibility. The portal does not provide hardware wiring advice that supersedes manufacturer documentation.

ESP32 DevKit

  • 240MHz dual-core Xtensa LX6
  • 520KB SRAM, 4MB Flash
  • Wi-Fi 802.11 b/g/n + BLE 4.2
  • GPIO: 34 pins (3.3V logic)
  • ADC: 12-bit, DAC: 8-bit
  • UART, SPI, I2C, I2S, PWM
  • Datasheet: espressif.com/en/products/socs/esp32

DHT22 Sensor

  • Temperature: -40 to 80°C (±0.5°C)
  • Humidity: 0–100%RH (±2–5%)
  • Supply voltage: 3.3–6V DC
  • Single-wire digital interface
  • 4.7kΩ pull-up resistor on data line
  • Sample rate: max 0.5 Hz

Raspberry Pi 4B

  • 1.8GHz quad-core Cortex-A72
  • 2/4/8GB LPDDR4 RAM
  • Wi-Fi 802.11ac, BLE 5.0
  • GPIO: 40-pin (3.3V logic — do NOT connect 5V to GPIO)
  • USB 3.0, Gigabit Ethernet, 2× micro-HDMI
  • OS: Raspberry Pi OS (Debian-based)

HC-SR04 Ultrasonic

  • Range: 2cm – 400cm
  • Supply: 5V (use voltage divider for 3.3V GPIO)
  • Trigger: 10µs pulse; Echo: proportional duration
  • Distance = (echo_time × 343 m/s) / 2
  • Beam angle: 15°
